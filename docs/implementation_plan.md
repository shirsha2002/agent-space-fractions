# Implementation plan and acceptance checklist

The deliverables are a Windows desktop Code Agent and a genuine Space Fractions desktop project generated by that agent from both original inputs. A fixture is only offline test data.

1. Preserve source attachments, compare the originals with the handoff, inspect the exact reference repositories and official API documentation.
2. Build an offline vertical slice: validate two UTF-8 inputs, retain hashes/text, index requirements with evidence, validate a model file manifest, materialize a fresh project, detect errors and exercise bounded repair with mocked responses.
3. Add the official DeepSeek client and a persistent conservative cumulative USD 1 ledger. Keep paid calls disabled until the exact model, prices, account access and bounded authorization are established.
4. Add a responsive desktop GUI with masked session key, both input selectors, output selector, start/cancel, status, logs, cost and result links. Include a bundled execution path so the packaged agent does not rely on `python` on PATH.
5. Run meaningful automated checks and Windows packaging. Distinguish host smoke tests from a clean machine with no pre-installed Python.
6. Perform one authorized real generation, review and test its output, repair only within the cap, package the genuine game and record provenance.
7. Complete the report, traceability, sanitized evidence, video demonstration and submission checklist. Publish only the intended sanitized software and generated artifacts.

- [x] Independent fraction/state/score checks and generated tests pass on the genuine DeepSeek-generated game. See the disclosed reviewed-output provenance.

- [ ] Evidence, report and video describe only observed behavior and disclose assistance.
